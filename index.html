      ตารางคัดแยกเคส → กอง → เจ้าของ

      อ้างอิงแนวปฏิบัติการขยายเวลาฯ มช. 2568/2569 · แถวของกรณีที่คัดได้จะถูกไฮไลต์ให้ทานอีกรอบ

      กรณีลักษณะงบ / สถานะเส้นทางพิจารณาเจ้าของเคสกันเงิน 3 มิติ?
      ข้อ 1 ก่อหนี้ผูกพันแล้ว — จัดซื้อ/จัดจ้าง มีใบสั่งซื้อ/สัญญา/ข้อตกลง เบิกไม่ทันสิ้นปีงบ กันเงินได้ไม่เกินไตรมาสที่สัญญาสิ้นสุด กองคลัง งานการเงินฯ ✓ การเงินทำต่อเนื่อง
      ข้อ 2 ก่อหนี้ไม่ทัน/อยู่ระหว่างดำเนินการ แต่ต้องใช้จ่ายต่อ (ค่าตอบแทน ใช้สอย วัสดุ) ขยายเวลาฯ ไม่เกินไตรมาสแรกปีถัดไป กองยุทธศาสตร์และแผนงานแล้วกันเงิน → กองคลัง งานแผน ✓ แผนส่งใบ → การเงินทำ
      ข้อ 3.1 เงินอุดหนุน ยังอยู่ในบัญชี 3 มิติ — โครงการสิ้นสุด หลัง ปีงบ กันเงินไม่เกินไตรมาสที่แผนสิ้นสุด · โครงการ ≥2 ปีงบ → ไม่เกินปีถัดไป กองคลัง งานการเงินฯ ✓ การเงินทำต่อเนื่อง
      ข้อ 3.2 เงินอุดหนุน ต้องเสร็จในปีงบ — งานเสร็จ แต่เบิกจ่ายไม่ทัน ขยายเวลาเบิกจ่าย ไม่เกินไตรมาสแรกปีถัดไป กองยุทธศาสตร์และแผนงานแล้วกันเงิน → กองคลัง งานแผน ✓ แผนส่งใบ → การเงินทำ
      ข้อ 3.3 เงินอุดหนุน ต้องเสร็จในปีงบ — ดำเนินโครงการไม่ทัน ขยายเวลาดำเนินการ+เบิกจ่าย ไม่เกินไตรมาสแรกปีถัดไป กองยุทธศาสตร์และแผนงานแล้วกันเงิน → กองคลัง งานแผน ✓ แผนส่งใบ → การเงินทำ
      ข้อ 4 เงินอุดหนุน เบิกออกจากบัญชี 3 มิติแล้ว แต่ยังไม่เบิก/ยังไม่ทำรายงานขอเบิก ขยายเวลาการเก็บรักษาเงินโครงการ กองยุทธศาสตร์และแผนงาน งานแผน — ไม่ต้อง
      ข้อ 4* งบดำเนินงานทำแล้ว เบิกไม่ทันปีงบ → ค่าใช้จ่ายค้างเบิกข้ามปี ข้อบังคับการเงิน 2567 ข้อ 27 — อธิการบดีอนุมัติ กองคลัง งานการเงินฯ — คนละกลไก

      จับกรณีเร็ว: ดูช่อง “กรณีกันเงิน” ที่ภาควิชาติ๊กมาในเอกสารแนบ เป็นตัวตั้งต้น แล้วยืนยันด้วยหลักเกณฑ์ข้างบน — สังเกตว่า ข้อ 2 / 3.2 / 3.3 แตะสองกอง (แผนก่อน แล้วคลัง) จึงต้องมีใบส่งงานกันเงินเสมอ
