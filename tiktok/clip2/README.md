# คลิป 2: หิวจริง หรือ หิวใจ? เช็กได้ใน 10 วินาที

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `clip2-emotional-hunger.mp4` | วิดีโอแนวตั้ง 1080×1920, 91.5 วินาที, มี CC ฝังบนจอแล้ว (ยังไม่มีเสียงพากย์/B-roll) |
| `clip2-emotional-hunger.srt` | ไฟล์ซับ ใช้ใน CapCut |
| `clip2-emotional-hunger-broll.txt` | ช่วงเวลาที่ต้องวาง B-roll แต่ละช็อต |
| `caption.txt` | แคปชันโพสต์ + แฮชแท็ก |
| `src/script.py` | ข้อความ/ซับ สร้างใหม่ด้วย `python3 tiktok/tools/render.py tiktok/clip2/src/script.py out.mp4` |

B-roll: ใน CapCut วางฟุตเทจเป็นเลเยอร์ "พื้นหลัง" ตามเวลาใน broll.txt แล้วลดความทึบของวิดีโอข้อความ หรือใช้ blend mode Screen ให้ข้อความลอยบนฟุตเทจ
